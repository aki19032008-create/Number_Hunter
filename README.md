# 🎯 NUMBER HUNTER

### Think. Guess. Win. ⚡

**Number Hunter** is a neon-themed number guessing game built using HTML, CSS, and JavaScript. Test your logic, challenge yourself, and find the secret number before your attempts run out!

🔗 **Live Demo:** Add your published website link here.

## ✨ Features

- 🎯 **Three Difficulty Levels** — Easy, Medium, and Hard
- 🔢 **Random Number Generation** — A new secret number for each game
- 💡 **Instant Feedback** — Find out if your guess is too high or too low
- ❤️ **Limited Attempts** — Challenge yourself to guess correctly
- 🏆 **Score System** — Earn points by winning
- 📊 **Leaderboard** — Track your best scores in your browser
- 🔊 **Sound Effects** — Arcade-style audio feedback
- 🌌 **Neon UI** — Dark futuristic design with glowing effects
- 🥷 **Neon Hunter Character** — A cyberpunk-inspired game mascot
- 📱 **Responsive Design** — Designed to work on different screen sizes

## 🕹️ How to Play

1. Open Number Hunter.
2. Choose your difficulty level.
3. Click **Start Game**.
4. Enter your guess.
5. Read the hints:
   - 🔵 **Too Low** — Try a higher number.
   - 🟣 **Too High** — Try a lower number.
   - 🏆 **You Win** — You found the secret number!
6. Try again and beat your best score.

## 🛠️ Built With

- **HTML5** — Website structure
- **CSS3** — Styling, animations, and neon effects
- **JavaScript** — Game logic and interactions
- **LocalStorage** — Saving scores and leaderboard entries in the browser

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start hunting numbers!

## 🌐 Deployment

This static website can be published for free using **GitHub Pages**.

1. Upload the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and wait for deployment.
6. Add the published URL to the Live Demo section above.

## 📌 Note

The leaderboard uses browser LocalStorage. Scores are stored locally in each player's browser and are not shared across all players.
